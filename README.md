# Microsoft Generative AI Notes

A beginner-friendly, interactive course on Generative AI and Large Language Models (LLMs), based on Microsoft's open-source curriculum. This project offers a clear, searchable interface for understanding key AI concepts and applications.

## 🚀 Live Preview

To view the notes in your browser:

1. Clone or download the repo.
2. Open `index.html` in any modern browser.

```bash
git clone https://github.com/msathyaanand/microsoft-generative-ai.git
cd /microsoft-generative-ai
open index.html
```

> You can also host it via GitHub Pages or any static site host.

## 📚 What's Included

- 🎓 Lesson-Based Navigation (20+ lessons)
- 🔍 Search functionality for quick keyword access
- 🧭 Sidebar with smooth scroll and section highlights
- 📌 Card-based layout with icons, key terms, and examples
- 💡 Key takeaways after every lesson
